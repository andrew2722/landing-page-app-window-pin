# Window Pin — landing page

Static site for [Window Pin](https://github.com/andrew2722/app-window-pin), a macOS
menu bar utility that holds another app's window at a fixed position and size and
provides an always-on-top panel for dropped content.

**Live:** https://andrew2722.github.io/landing-page-app-window-pin/

One `index.html` with inline CSS — no build step, no dependencies. Edit and push;
GitHub Pages serves the repository root of `main`.

Download links point at the latest release in the application repository, so the
site needs no changes when a new version ships.
